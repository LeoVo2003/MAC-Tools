# 2.1 Hybrid HTTP — createUser + Mac Role + Web Info

**Ngày:** 2026-07-29  
**Tag nền:** `v2.0.0` · bản này: `2.1.0`

## Mục tiêu

Giảm thời gian các bước form/AJAX rõ bằng HTTP/DOM trong Chrome (`fetch` + credentials), fail → fallback click Chrome cũ.

## Đã có

| Bước | HTTP |
|---|---|
| Tạo user | DOM nonce → POST `user-new.php` |
| Mac Core Install | `mac_core_install_plugin` + `plugin_slug=mac-role` |
| Mac Core Activate | GET `action=activate&addon=mac-role&_wpnonce=` |
| Create F | `rud_apply_template` + `template_id=f_package_user` |
| Web Info | Vue patch + AJAX / click Update |

## Flag

- `USE_HTTP_STEPS=1` (mặc định)
- `USE_HTTP_STEPS=0` — chỉ Chrome

## Ngoài scope

- Sync WPM / Backup thuần HTTP
- Login WPM thuần HTTP
