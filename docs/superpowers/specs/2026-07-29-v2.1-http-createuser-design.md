# 2.1 Hybrid HTTP — createUser

**Ngày:** 2026-07-29  
**Tag nền:** `v2.0.0` trên `develop` / `main`

## Mục tiêu

Giảm thời gian bước **Tạo tài khoản khách** bằng HTTP POST `user-new.php`, vẫn dùng Chrome cho login / Quick Login / các bước UI phức tạp.

## Thiết kế

1. Sau Quick Login, lấy cookie từ `page.cookies(origin)`.
2. `GET /wp-admin/users.php?s=email` — bỏ tạo nếu email đã có.
3. `GET /wp-admin/user-new.php` → lấy `_wpnonce_create-user`.
4. `POST` form (role=editor, `pw_weak=on`, không gửi notification).
5. Fail hoặc không xác nhận được → **fallback Chrome** (flow cũ).

## Flag

- `USE_HTTP_STEPS=1` (mặc định) — bật HTTP createUser  
- `USE_HTTP_STEPS=0` — chỉ Chrome  

Target web (Main / khớp ô Website) **không đổi** — HTTP chạy trên đúng origin sau Quick Login.

## Ngoài scope 2.1

- Sync WPM / Backup / Mac Role bằng HTTP (UI WPM phức tạp; giữ Chrome).
- Login WPM thuần HTTP.

## Kiểm thử

1. Fill + Run chỉ tick **Tạo tài khoản khách** (và sync nếu cần).  
2. Log có `Tạo user (HTTP)` hoặc `Đã tạo ... qua HTTP`.  
3. Cố tình sai cookie / tắt mạng HTTP → thấy `fallback Chrome` rồi vẫn tạo được.
